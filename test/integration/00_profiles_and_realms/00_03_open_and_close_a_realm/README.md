# 00.03 Open and close a Realm

## Agent job

Ask an agent to open a permitted Profile, write a note, and close its session. Repeat on a borrowed placement where the binding supports one.

## Fixture and variants

Start with a disposable Local directory, a borrowed Local directory, and independent Memory stores. For each backend supply its approved placement inputs. Observe the resource or store and any lease outside the agent.

## Pass conditions

- The opened instance reports its Realm identity and effective capabilities. The host observer confirms the bound placement. A closed session cannot write. Closing a second time has the same effect as closing once.
- Close cleans up a disposable placement and preserves a borrowed placement as configured. The observer checks this before fixture cleanup.
- Repeat with a different compatible binding for a new instance of the same Profile. Each instance has an independent identity and session.
