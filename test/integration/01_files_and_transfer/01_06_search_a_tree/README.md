# 01.06 Search a tree

## Agent job

Ask an agent to find a known phrase and read the matching files in an approved subtree.

## Fixture and variants

Use a searchable Profile bound to the allowed subtree. Seed matching text, a binary file, and a separate tree outside the binding.

## Pass conditions

- Results use Realm-relative paths and report applicable limits. Matches in the permitted subtree can be read. Results omit the excluded subtree.
