# 03.06 Use an interactive run

## Agent job

Ask the agent to start a program that waits for input, send a fixed value, and inspect the response.

## Fixture and variants

Use an execution profile that declares interactive input. Exercise normal completion and client disconnect.

## Pass conditions

- Input reaches the selected run. An observer can match the reply to that run. Disconnect follows the declared stop or retention policy.
