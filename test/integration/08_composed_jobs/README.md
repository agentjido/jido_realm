# 08 Composed agent jobs

The coding agent is the reference application. The same repository fix
and test runs on each qualifying execution binding. A reviewer can open
a saved artifact from the run or use a private route to review the live
application. Choose the presentation contract that the job requires.

- [08.01 Copy to a sandbox and preview](08_01_copy_and_preview_on_a_sprite/README.md)
- [08.02 Build, test, and hand off](08_02_build_test_and_hand_off/README.md)
- [08.03 Publish and show an HTML artifact](08_03_publish_and_show_an_html_artifact/README.md)

The coding repair and saved HTML cases run through Realm. The live-app
preview case still uses the Apple Container example as partial evidence.
